How this site was made

CURRENT was designed and built end-to-end by Claude (Fable 5), working autonomously: concept, art direction, copywriting, custom shaders, animation and deployment. This page is the honest recipe, so you can do the same.

01Concept before code

Every strong site starts as a sentence, not a wireframe. The brief here: "low-voltage wiring is the invisible nervous system of a building" — so the whole experience behaves like signal: dark space, thin lines of light, pulses that travel. Palette, type and motion were all locked before any HTML existed:

PaletteInk blue-black #04060e, electric ultramarine #2438ff, warm paper #f0efe9, one drop of vermilion #ff4d26 reserved for "live" moments.
TypeSyne (variable, 800 for display), Space Grotesk for prose, IBM Plex Mono for HUD labels. All self-hosted as woff2.
Motion lawEverything eases with cubic-bezier(0.22,1,0.36,1); nothing fades from nowhere — content rises out of masked lines.

02The WebGL hero: one fragment shader

The hero is not a video or a particle library preset. It is a single custom GLSL fragment shader drawn on a fullscreen triangle with Three.js:

  • Six "filaments" — each one is the distance from the pixel to a curve whose shape is layered value noise drifting over time. Distance becomes light: 0.0016 / (d + 0.0016) gives the hot core, a wider term gives the halo.
  • Travelling pulses — a fract(x - time · rate) sawtooth pushed through a sharp gaussian makes white packets of light run down each line at different speeds.
  • Cursor bends the field — a gaussian displacement centered on the mouse pushes the filaments away, so the signal feels alive under your hand.
  • The background is a two-stop gradient plus fractal noise nebula, a drifting dot grid tied to scroll, a vignette, and a dither pass to kill gradient banding.

DPR is capped at 1.75 and the render loop pauses when the hero leaves the viewport or the tab hides — spectacle should never cost battery in the background.

03Scroll choreography

Lenis provides inertial scrolling, bridged into GSAP ScrollTrigger through the GSAP ticker (autoRaf: false) so scrubbed animations never stutter. The set pieces:

  • A manifesto that inks up word by word (SplitText) as you scrub past it.
  • A pinned horizontal gallery: the page scrolls down, the work track slides sideways, inner images counter-parallax, and a mono counter tracks 01 / 04.
  • An SVG process line that draws itself via stroke-dashoffset, igniting each step node as it passes.
  • A marquee whose speed is tied to scroll velocity, magnetic buttons via GSAP transforms, and a custom cursor with a lerped trailing ring.
  • Stat counters, circuit traces, masked headline rises — all reduced-motion aware: prefers-reduced-motion collapses the site to a calm static read.

04AI-generated art direction

The four project photographs are generated, not stock — created with Higgsfield's nano banana pro image model from prompts written to match the locked palette ("a single continuous line of deep ultramarine cobalt LED light…"). Because every image obeys the same palette and lighting rules, the gallery reads as one photographer's portfolio. A GitHub Actions step downloads each render, resizes it and recompresses it to progressive JPEG at build time.

05The exact stack

MarkupHand-written semantic HTML. No framework, no build step — the page you are reading is the source.
RenderingThree.js (custom ShaderMaterial, orthographic fullscreen quad).
MotionGSAP 3 + ScrollTrigger + SplitText, Lenis smooth scroll.
FontsSyne · Space Grotesk · IBM Plex Mono, self-hosted variable woff2 (via Fontsource).
ImageryHiggsfield generate_image (nano banana pro), optimized in CI with ImageMagick.
HostingStatic files → GitHub Pages via Actions. The same folder deploys to Netlify unchanged: netlify deploy --prod --dir current.

06Do it yourself

  1. Write the one-sentence concept and ban yourself from generic choices: no default blue-purple gradients, no Inter, no hero stock photo.
  2. Lock palette + two or three typefaces, self-host them, and define one easing curve for the whole site.
  3. Build the page fully static first. Then add one signature interactive piece (here: the shader) and let every other animation stay quiet and supportive.
  4. Generate imagery with prompts that repeat your palette and lighting rules verbatim, so all assets look like one shoot.
  5. Test with screenshots at desktop and mobile widths, fix, repeat — this site went through three full critique passes before shipping.
  6. Ship static. Any host works: GitHub Pages, Netlify (drop the folder onto app.netlify.com/drop), Vercel, a $4 VPS.
